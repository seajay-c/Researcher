**Searx** ([/sɜːrks/](https://en.wikipedia.org/wiki/Help:IPA/English "Help:IPA/English"); stylized as **searX**) is a discontinued [free](https://en.wikipedia.org/wiki/Free%5Fsoftware "Free software") and [open-source](https://en.wikipedia.org/wiki/Open-source "Open-source") [metasearch engine](https://en.wikipedia.org/wiki/Metasearch%5Fengine "Metasearch engine"),[\[4\]](#cite%5Fnote-4) available under the [GNU Affero General Public License version 3](https://en.wikipedia.org/wiki/GNU%5FAffero%5FGeneral%5FPublic%5FLicense "GNU Affero General Public License"), with the aim of protecting the [privacy](https://en.wikipedia.org/wiki/Privacy "Privacy") of its users.[\[5\]](#cite%5Fnote-5)[\[6\]](#cite%5Fnote-6)[\[7\]](#cite%5Fnote-7) To this end, Searx does not share users' [IP addresses](https://en.wikipedia.org/wiki/IP%5Faddress "IP address") or search history with the [search engines](https://en.wikipedia.org/wiki/Search%5Fengine "Search engine") from which it gathers results. [Tracking cookies](https://en.wikipedia.org/wiki/HTTP%5Fcookie#Tracking "HTTP cookie") served by the search engines are blocked, preventing [user-profiling-based results modification](https://en.wikipedia.org/wiki/Filter%5Fbubble "Filter bubble").[\[8\]](#cite%5Fnote-8)[\[9\]](#cite%5Fnote-9) By default, Searx queries are submitted via [HTTP POST](https://en.wikipedia.org/wiki/HTTP%5FPOST "HTTP POST"),[\[a\]](#cite%5Fnote-11) to prevent users' query keywords from appearing in webserver logs.[\[10\]](#cite%5Fnote-about.html-10)[\[11\]](#cite%5Fnote-preferences-12) Searx was inspired by the [Seeks](https://en.wikipedia.org/wiki/Seeks "Seeks") project,[\[10\]](#cite%5Fnote-about.html-10) though it does not implement Seeks' [peer-to-peer](https://en.wikipedia.org/wiki/Distributed%5Fsearch%5Fengine "Distributed search engine") user-sourced results [ranking](https://en.wikipedia.org/wiki/Ranking%5F%28information%5Fretrieval%29 "Ranking (information retrieval)").

Each search result is given as a direct link to the respective site, rather than a [tracked redirect link](https://en.wikipedia.org/wiki/Internet%5Ftracking "Internet tracking") as used by [Google](https://en.wikipedia.org/wiki/Google%5FSearch "Google Search"). In addition, when available, these direct links are accompanied by cached and/or proxied links that allow viewing results pages without actually visiting the sites in question. The cached links point to saved versions of a page on the [Wayback Machine](https://en.wikipedia.org/wiki/Wayback%5FMachine "Wayback Machine"), while the proxied links allow viewing the current live page via a Searx-based [web proxy](https://en.wikipedia.org/wiki/Web%5FProxy "Web Proxy"). In addition to the general search, the engine also features tabs to search within specific domains: files, images, [Information technology](https://en.wikipedia.org/wiki/Information%5Ftechnology "Information technology"), maps, music, news, science, social media, and videos.[\[12\]](#cite%5Fnote-13)[\[13\]](#cite%5Fnote-golem.de-14)

Users can run private instances of Searx on their own computer, but there are also many public, user-run, Searx instances,[\[14\]](#cite%5Fnote-Searx%5Finstances-15) some of which are available as [Tor](https://en.wikipedia.org/wiki/Tor%5F%28anonymity%5Fnetwork%29 "Tor (anonymity network)") [hidden services](https://en.wikipedia.org/wiki/Hidden%5Fservice "Hidden service").[\[14\]](#cite%5Fnote-Searx%5Finstances-15) Meta-Searx instances can also be used to forward the search query to a random public instance.[\[14\]](#cite%5Fnote-Searx%5Finstances-15) A public [API](https://en.wikipedia.org/wiki/API "API") is available for Searx,[\[15\]](#cite%5Fnote-16)[\[16\]](#cite%5Fnote-17) as well as [Firefox](https://en.wikipedia.org/wiki/Firefox "Firefox") search provider plugins.[\[17\]](#cite%5Fnote-18)

As of 7 September 2023, the Searx [GitHub](https://en.wikipedia.org/wiki/GitHub "GitHub") repository has been archived, stating that SearX is no longer maintained.[\[18\]](#cite%5Fnote-19) [SearXNG](https://en.wikipedia.org/wiki/SearXNG "SearXNG"), forked from Searx, maintains a repository.[\[19\]](#cite%5Fnote-:0-20)

## Search engines and other settings

\[[edit](/w/index.php?title=Searx&action=edit&section=1 "Edit section: Search engines and other settings")\]

Across all categories, Searx can fetch search results from about 82 different engines. This includes major search engines and site-specific searches like [Bing](https://en.wikipedia.org/wiki/Bing%5F%28search%5Fengine%29 "Bing (search engine)"), [Google](https://en.wikipedia.org/wiki/Google%5FSearch "Google Search"), [Reddit](https://en.wikipedia.org/wiki/Reddit "Reddit"), [Wikipedia](https://en.wikipedia.org/wiki/Wikipedia "Wikipedia"), [Yahoo](https://en.wikipedia.org/wiki/Yahoo!%5FSearch "Yahoo! Search"), and [Yandex](https://en.wikipedia.org/wiki/Yandex%5FSearch "Yandex Search").[\[20\]](#cite%5Fnote-Tauber-21) The engines used for each search category can be set via a "preferences" interface, and these settings will be saved in a cookie in the user's web browser, rather than on the server side, since for privacy reasons, Searx does not implement a [user login](https://en.wikipedia.org/wiki/Login "Login") model. Other settings such as the search interface language and the search results language (over 20 languages are available) can be set the same way.[\[11\]](#cite%5Fnote-preferences-12)

In addition to the preferences cookie, it is possible on each query to modify the engines used, search categories selected, and/or languages to search in by specifying one or more of the following textual search operators _before_ the search keywords.[\[21\]](#cite%5Fnote-22)

* `!_category_` — Search the specified _category_ instead of the default ones.
* `?_category_` — Search the specified _category_ in addition to the default ones.
* `!_engine_` — Search the specified _engine_ instead of the default ones.
* `?_engine_` — Search the specified _engine_ in addition to the default ones.
* `:_language_` — Search for results in the specified _language_ instead of the default one.

The `!` and `?` operators can be specified more than once to select multiple categories or engines, for example `!google !deviantart ?images :japanese cow`.

## Instances

\[[edit](/w/index.php?title=Searx&action=edit&section=2 "Edit section: Instances")\]

Any user may run their own instance of Searx,[\[22\]](#cite%5Fnote-23) which can be done to maximize privacy, avoid congestion on public instances, preserve customized settings (even if browser cookies are cleared), allow auditing of the source code being run, and more.[\[23\]](#cite%5Fnote-own-instance-24) Users may include their Searx instances on the editable list of all public instances, or keep them private.[\[20\]](#cite%5Fnote-Tauber-21)[\[23\]](#cite%5Fnote-own-instance-24) It is also possible to add custom search engines to a [self-hosted](https://en.wikipedia.org/wiki/Self-hosting%5F%28web%5Fservices%29 "Self-hosting (web services)") instance that are not available on the public instances.[\[24\]](#cite%5Fnote-25)In 2019, Google has begun to block some self-hosted instances. This included some of the IP addresses used by searx.me from queries that result in a `google (unexpected crash: CAPTCHA required)` error.[\[25\]](#cite%5Fnote-26) In response, some instances have been modified to silently skip trying to search with Google even when it's the only engine specified.[\[26\]](#cite%5Fnote-27)[\[27\]](#cite%5Fnote-28)

## SearXNG fork

\[[edit](/w/index.php?title=Searx&action=edit&section=3 "Edit section: SearXNG fork")\]

[![SearXNG-wordmark](//thumb.wikimedia.org/wikipedia/commons/thumb/b/b7/SearXNG-wordmark.svg/250px-SearXNG-wordmark.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:SearXNG-wordmark.svg)

SearXNG-wordmark

Main article: [SearXNG](https://en.wikipedia.org/wiki/SearXNG "SearXNG")

In the middle of 2021, some contributors of SearX forked the repo to [SearXNG](https://en.wikipedia.org/wiki/SearXNG "SearXNG") with a view to provide faster debugging and fixes of engine errors.[\[28\]](#cite%5Fnote-29) SearXNG is for users that need a faster upstream development time with fewer bugs.[\[29\]](#cite%5Fnote-30)[\[19\]](#cite%5Fnote-:0-20) User theme, engine reliability and anonymous metrics are the most notable changes in SearXNG.[\[19\]](#cite%5Fnote-:0-20)
