**SearXNG** is a [metasearch engine](https://en.wikipedia.org/wiki/Metasearch%5Fengine "Metasearch engine") forked from the discontinued [searX](https://en.wikipedia.org/wiki/SearX "SearX"). It is [free and open-source](https://en.wikipedia.org/wiki/Free%5Fand%5Fopen-source%5Fsoftware "Free and open-source software") and, similarly to searX, does not collect information about users.[\[1\]](#cite%5Fnote-:2-1)

## Instances

\[[edit](/w/index.php?title=SearXNG&action=edit&section=1 "Edit section: Instances")\]

SearXNG is server-side software, and as such is hosted by several instances, public and private. Private instances are hosted on a local network, or run on the user's desktop computer itself, and are designed to be used by one person or a small number of people. Public instances are hosted on public web servers and are designed to be used by anyone like a typical search engine.[\[2\]](#cite%5Fnote-:3-2) A list of public instances is available at [searx.space](https://searx.space).[\[3\]](#cite%5Fnote-:1-3)

## Features

\[[edit](/w/index.php?title=SearXNG&action=edit&section=2 "Edit section: Features")\]

### Categorical searching

\[[edit](/w/index.php?title=SearXNG&action=edit&section=3 "Edit section: Categorical searching")\]

SearXNG can separate results into multiple categories, including the standard categories of "General, "[Images](https://en.wikipedia.org/wiki/Image%5Fretrieval "Image retrieval")," "[Videos](https://en.wikipedia.org/wiki/Video%5Fsearch%5Fengine "Video search engine")," and "[News](https://en.wikipedia.org/wiki/News "News")," as well as the non-standard categories of "[Social Media](https://en.wikipedia.org/wiki/Social%5Fsearch "Social search")," "[Music](https://en.wikipedia.org/wiki/Audio%5Fsearch%5Fengine "Audio search engine")," "Files," "[IT](https://en.wikipedia.org/wiki/Information%5Ftechnology "Information technology")," and "[Science](https://en.wikipedia.org/wiki/Science "Science")."[\[4\]](#cite%5Fnote-4)

### Engines

\[[edit](/w/index.php?title=SearXNG&action=edit&section=4 "Edit section: Engines")\]

As a metasearch engine, SearXNG functions by sending queries to upstream search engines and returning them to the user. As of 2023, more than 70 different search engines are supported, including [Google](https://en.wikipedia.org/wiki/Google%5FSearch "Google Search"), [Bing](https://en.wikipedia.org/wiki/Microsoft%5FBing "Microsoft Bing"), [DuckDuckGo](https://en.wikipedia.org/wiki/DuckDuckGo "DuckDuckGo"), and [Qwant](https://en.wikipedia.org/wiki/Qwant "Qwant").[\[2\]](#cite%5Fnote-:3-2)[\[3\]](#cite%5Fnote-:1-3) As of 2026, SearXNG lists 251 possible search services to search from.[\[5\]](#cite%5Fnote-5) SearXNG also supports "bangs", searching only a particular engine if an exclamation point and shortcut key are appended before the search. Using two exclamation marks, such as "!!w", functions like [DuckDuckGo](https://en.wikipedia.org/wiki/DuckDuckGo "DuckDuckGo")'s version of bangs, redirecting to the external engine itself.[\[6\]](#cite%5Fnote-z085-6)

### Privacy

\[[edit](/w/index.php?title=SearXNG&action=edit&section=5 "Edit section: Privacy")\]

SearXNG removes private data from requests sent to search services. SearXNG itself stores little to no information that can be used to identify users.[\[1\]](#cite%5Fnote-:2-1)[\[2\]](#cite%5Fnote-:3-2) Some search engines are based in the United States, which makes law enforcement requests for user data to US-based digital services; any information stored on a SearXNG engine based outside the US is not affected.[\[7\]](#cite%5Fnote-7)
