## Q: Which companies or projects created and maintain MCP?

## Creators and Maintainers of MCP

### Original creators

MCP was created at **Anthropic** by engineers **David Soria Parra** and **Justin Spahr-Summers**, and was announced on November 25, 2024 [1][4][8].

### Governance and stewardship

In December 2025, Anthropic donated MCP to the **Agentic AI Foundation (AAIF)**, a directed fund under the **Linux Foundation**, co-founded by Anthropic, **Block**, and **OpenAI**, with support from other companies [4]. The project is now operated as "Model Context Protocol, a Series of LF Projects, LLC" [6][8].

The protocol is maintained by a distributed community: **58 maintainers** support **9 core/lead maintainers** in the MCP steering group, with **2,900+ contributors** in the Discord community and 100+ new contributors joining every week [7].

### Key contributing companies and projects

The following organizations are prominent contributors, partners, or first-class adopters shaping MCP's development:

| Company / Project | Role |
|---|---|
| **Anthropic** | Creator; co-founder of AAIF [4][6] |
| **OpenAI** | Co-founder of AAIF; adopted MCP in March 2025 across ChatGPT and its developer platform [4][7] |
| **Block** (Square) | Co-founder of AAIF; built Square AI and Moneybot on MCP [4][7] |
| **Microsoft** | Integrates MCP into Microsoft Foundry, Azure, and VS Code [2][6][7] |
| **Google Cloud** | Supports MCP across Gemini, Gemini CLI, and Cloud databases [6][7] |
| **AWS** | Built MCP into Amazon Bedrock, AgentCore, Kiro, Strands, and Quick Suite; contributed the Tasks extension [6][7] |
| **Cloudflare** | Deploys MCP servers in Workers; supports the 2026-07-28 spec from day one [6] |
| **GitHub** | Official MCP server, registry, and enterprise allowlist controls [7] |
| **Hugging Face** | HF-MCP server for model management and dataset search [7] |
| **Figma** | MCP server for bringing generated outputs into Figma's canvas [6][7] |
| **Okta** | Cross App Access authorization extension [7] |
| **Supabase, Sentry, Linear, Notion, Stripe, Postman, Netlify, Honeycomb** | Active server implementers / spec validators [6][7] |

In short, MCP began as an Anthropic project, is now governed under the Linux Foundation's Agentic AI Foundation (co-founded by Anthropic, Block, and OpenAI), and is actively maintained by a large distributed community of maintainers and contributors from the companies above [4][6][7][8].

## Q: What license is the MCP specification published under?

The MCP specification is published under the **MIT License** [8]. This is stated in the README of the official `modelcontextprotocol/modelcontextprotocol` GitHub repository, which contains the specification, protocol schema, and documentation [8].
